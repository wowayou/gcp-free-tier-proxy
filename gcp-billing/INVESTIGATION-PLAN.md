## 3. 三类流量口径必须分开

| 口径 | 正确解释 |
| --- | --- |
| HY2 tx/rx | 客户端视角的上传/下载业务字节；保守补记必须另列，不能当作实验流量 |
| VM 网卡发送/guard | 包括 VM→客户端回程、VM→目标站、Reality、系统流量、协议/重传开销；不是 HY2 下载量或收费量 |
| Billing SKU | Google 分类后的结算用量/抵扣/费用；与前两者不要求精确相等 |

HY2 入口是 UDP/QUIC，不代表它向目标站发出的业务连接全部是 UDP。比较 HY2 与 Reality 会改变传输和重传开销，不能仅因费用同步变化就认定存在“UDP 附加费”。

## 4. 分阶段执行与门禁（保留方案，非待执行清单）

### A. 先补证据，不动生产（推荐先做）

1. 保留原 CSV；后续用户从现有 Billing Reports 导出相同时间/币种/抵扣口径、明确项目过滤的逐日 SKU 数据。沿用控制台，不为方便调查新建导出服务。
2. 回复原工单，索取：该 SKU 的精确定价/生效日期、STANDARD 流量归入该 SKU 的适用规则、是否可关闭或规避、ASN 示例和中转建议的证据；另请澄清官方概览页与定价页的免费额度口径冲突（见第 6 节）。要求把未核实部分明确列出。
3. 把账单时区、查询周期、导出时间与 UTC 现场时间对应起来；计费按使用时间还是发票月份须记录，不能混用。
4. 人工跟进最多两轮，第二轮后仍无证据则标为“计费政策未核实，停止升级调查”；不转付费支持、不无限等待或反复提同一问题。

**A 验收：**每个结论有证据类型、URL/文件、时间及适用范围；核对原始费用而非仅 $1.01 展示值。无法取得依据时允许完成证据整理，但**计费政策验收为未通过**，不是默认认可客服推断。

### B. 有限被动观察（另行批准一次管理窗口）

建议上限：20 分钟窗口、一次既有 SSH/IAP 连接；10 分钟内最多 12 组、间隔至少 60 秒的本机只读快照。无需云 API 轮询；若要补查资源配置，另列请求清单，总计最多 12 个只读请求、每次 20 秒、不重试，权限/接口关闭即停止对应调查。

- 前后读取 `hy2-admin status`、`/run/gcp-egress-guard/status.json`、必要的 `systemctl show`，核对采样新鲜度、错误、进程代次、保护、配额及补记未改变。
- 网卡累计与已有 socket/conntrack 信息仅作观察；只用已安装且已审阅的只读命令，不启用 conntrack 计量或连接日志来“补数据”。
- 首先区分“客户端回程”“目标服务方向”“管理/系统”“无法分类”；原始端点只留私密本地材料，总量上限 5 MiB，无载荷，超过上限停止采集。不向控制台输出完整端点列表。
- `ss` 是瞬时连接视图，conntrack 字节计数未必启用，既有 warn 日志未必含成功连接。缺少字节时填“未知”，不能用连接次数推算流量占比，也不能把没看到短连接视为不存在。
- 不直接请求 HY2 核心统计接口；尤其禁止 `/traffic?clear=1`，也不调用 `health run` 或 `gcp-egress-guard --status`。复用现有只读账本视图，避免干扰唯一采集器。

**B 验收：**形成角色化流量候选表和覆盖缺口；只有存在可核验的字节来源才填写字节与方向。它最多证明“候选通信对象/方向”，**不签署收费 SKU 归属**。服务/保护状态异常、采样超过既有新鲜度要求、进程代次变化、计数回退/跨计费月、无法脱敏或工具需安装时立即停止，不现场修复。

### C. 有限对照验证（条件分支，不默认执行）

只有 A/B 足以选出一个具体候选，且存在不依赖新增收费服务的观测方式，才准备实验清单。先审查账单时间粒度、精度和其他生产流量：若实验无法与背景或舍入误差区分，不发送流量，结论保留未知。

建议试验上限（**不是已授权额度**）：最多四个可在账单中区分的窗口，单窗口主动传输业务量不超过 32 MiB、时间不超过 120 秒、并发 1、重试 0，全部业务量合计不超过 128 MiB；观察最长七天。每个窗口只改一个变量，两个配对重复采用同一判读标准。

实验前必须另行确认：

- 精确客户端/目标、方向、协议、窗口和控制变量；不通过停全服或暂停保护制造安静环境。其他用户如需停止使用，必须先征得同意。
- 固定长度的收发对象、请求/连接/重定向上限和实际执行器；禁止测速、无限流、自动重连及失败后放大样本。
- 业务字节上限不是网卡硬上限，重传/响应/背景流量须单独评估。给出可执行的实验收发/时间停止控制、可验证的费用或请求授权范围及风险；无法把所需收费操作限制在授权范围内则不执行。不能拿 $0.08/GiB、预算邮件或 180 GiB 采样保护充当财务硬封顶。
- 账单读数最多三轮人工复查（基线、最后一个实验窗口后至少 48 小时、七天截止前），不自动轮询。账单仍在修订或粒度不足则记为未决，不通过增加流量“刷出差异”。

**C 验收：**实际运行与控制变量清单一致；无后台混杂无法解释、重连/超量/代次变化；两组配对趋势一致且变化超过账单舍入与已量化背景波动；统计对象、方向、日期与 SKU 可对应。满足这些条件只证明**该窗口/路径的关联**；若要宣称计费规则或普遍因果，还须官方依据或更强独立证据。达不到可分辨性即停止，不能仅用延迟账单中的“暂时为零”判通过。

### D. 按证据选择最小处理，再验收

优先顺序：

1. 费用可接受：用户明确接受实际费用与不确定性后保持架构，人工看账单；接受费用不等于查明根因。
2. 确认是非必要目标服务：优先客户端精确分流/减少该业务；不把“直连”默认用于需要代理或涉及隐私的目标，不扩大到整个 ASN。
3. 确认是 VM→客户端方向：网站规则不能控制这段回程；另行比较接入网络/节点位置/其他方案的实际成本与访问要求。不得承诺切 TCP 或改区域就免费。
4. 所有中转、新资源、服务端 ACL/防火墙或额度调整均另立授权与回滚清单，不属于本方案默认执行。

**D 验收：**明确用户接受的月成本目标、一次性成本和维护负担；对同类任务比较单位业务量的收费而非只看总账单下降；最多七天人工观察到期结案或标记未决，不自动延长。用户指定的关键访问任务通过，原客户端/备用及配额保护未回归，未新增未经授权费用。若变更涉及服务端，先走维护手册的备份/配置校验/授权恢复流程，不能临时重启 accountd。仅撤回本次改动，不恢复旧无额度 HY2 配置。
